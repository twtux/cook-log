# Pre-Cook Prep Checklist ✅🔥

The master "don't forget anything" list, timed out from a few days before down to fire time. Skim it before every cook; the protein-specific callouts are at the bottom.

---

## 2–3 days out
- [ ] **Buy the meat.** Right cut + weight for the crowd (budget ~½ lb cooked per person; brisket/pork butt lose ~40% so buy ~¾–1 lb raw per person).
- [ ] **Thaw** if frozen, in the fridge, not the counter. Rule: ~24 hrs per 5 lb. A packer brisket needs 2–3 full days.
- [ ] **Start the dry brine** on big cuts (brisket, pork butt, thick steaks): kosher salt, **½ tsp Diamond Crystal per lb**, uncovered on a rack in the fridge. Poultry for crispy skin → air-dry uncovered too.
- [ ] Check you have fuel: **enough charcoal/briquettes** for the whole cook + a bag in reserve, and a **wood chunk** (apple / cherry / pecan for poultry + pork; oak / hickory for beef).

## Night before
- [ ] **Trim** the cut (fat cap to ~¼", square edges, pull silverskin). Save trim for a burger grind or beans.
- [ ] **Injection** for big cuts (brisket → beef broth + Worcestershire; pork → apple juice + cider vinegar + brown sugar). See `flavor-prep.md`.
- [ ] **Mix the rub** (shake jar ready) — see `flavor-prep.md`.
- [ ] **Make the sauce** (better after a night in the fridge) — see `sauces.md`.
- [ ] **Wet brine** poultry if going that route (never both wet brine AND salt again — Tom's rule).
- [ ] Prep sides that hold: chop **yellow onion**, dice **thick-cut bacon**, shred cheese. See `sides.md`.
- [ ] **Stage gear** (checklist below) so morning-of is grab-and-go.
- [ ] Charge the **Venom controller** + phone; fresh batteries in the **instant-read pen**.

## Morning of / 3–4 hrs before eating
- [ ] **Pull the meat from the fridge** to knock the chill off (~45–60 min for big cuts) while the pit comes up.
- [ ] **Binder + rub** (thin yellow-mustard coat if you want it to stick), let it sweat 30–60 min.
- [ ] **Fire setup** — light a small chimney (~8–12 briquettes), get them gray/glowing, dump onto a concentrated unlit bed by the Venom fan. Confirm coals actually catch before closing the lid. (Tom's #1 rule — a spread-out ring stalls.)
- [ ] Add the **wood chunk** once coals are ashed over.
- [ ] Set target pit temp; let it **stabilize** before the meat goes on.
- [ ] Probes: leave-in in the **dead center of the thickest part** (not fat/bone); instant-read for spot checks.

## At the pit
- [ ] **Meat on**, note the time (text me — starts the timeline).
- [ ] **Spritz bottle** filled (cider vinegar + water/juice) for after the bark sets (~2 hrs in).
- [ ] **Wrap material** ready (butcher paper or foil) for the stall.
- [ ] **Cooler + towels** for the rest (a 1–2 hr faux-cambro rest is where brisket is won).
- [ ] Water/beer, and a chair. Long cooks are a marathon.

## Gear checklist
- Chimney starter + fire starters (Jealous Devil BOOM)
- Charcoal + reserve bag + wood chunks
- Venom PID controller (charged) + phone
- Instant-read pen (ThermoPro) + leave-in probe
- Nitrile gloves + insulated gloves
- Butcher paper / heavy foil
- Spray bottle (spritz)
- Sharp slicing knife + cutting board with a juice groove
- Half-pans / cast iron for sides + drippings
- Cooler + old towels (rest)
- Trash bag, paper towels

## Protein-specific quick notes
- **Brisket:** salt + pepper only (no sugar — burns over 12+ hrs). Inject. Wrap at ~165–170 to beat the stall. Rest 1–2 hrs. Slice flat across the grain, then rotate the point 90°.
- **Pork butt:** rub with sugar OK. Inject apple. Pull at ~203. Rest 1 hr, then shred + toss in Carolina vinegar sauce.
- **Ribs:** light rub, no injection. 3-2-1 (spares) or 2-2-1 (baby backs). Glaze last 30 min.
- **Rotisserie chicken:** ONE salt step only (Tom's rule). 2-day air-dry for skin. Run **325–350°F** (not 275 — soft skin). Pull breast 160–165 / thigh 175. One fruit-wood chunk.
- **Burgers (self-grind):** keep meat + grinder parts near-frozen. ~80/20. Don't overwork. Salt the outside only, right before the sear.
